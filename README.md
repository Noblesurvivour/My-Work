# Employee Data Analysis using PivotTables

An interactive HR dashboard created in Microsoft Excel to analyse employee data.

## Skills Demonstrated

- PivotTables
- PivotCharts
- Slicers
- KPI calculations
- Employee count analysis
- Salary analysis
- Average salary by position
- Top 10 positions by average salary
- Top 10 positions by employee count
- Nationality analysis
- Dashboard design

## Dashboard Features

This dashboard helps users explore employee data through interactive slicers, charts, and key performance indicators.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
